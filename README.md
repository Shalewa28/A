Weather Checker Application
Overview
A Python program that lets users enter a city name and view real-time weather data (temperature, conditions, humidity) using OpenWeatherMap.
Features
Enter any city
View temperature, weather condition, and humidity
Handles invalid input
Can check multiple cities
How to Run
Install requests:
pip install requests
Add your API key in the code
Run:
python weather_app.py
